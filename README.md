# 現金水位儀 · Cash-Weight Gauge

用「趨勢動能 × 真實 VIX」的**聯集**策略,計算 S&P 500 建議的現金比重(0–100%)。
純靜態 PWA — 沒有建置流程、沒有相依套件、沒有後端,丟上 GitHub Pages 就能跑。

**線上版:** https://marschannewtag-spec.github.io/mars-robot/

## 策略邏輯

兩條腿各自算出建議現金,**取較高者**(聯集)。

**趨勢動能腿** — S&P 月收相對 12 月均線的乖離率:

| 乖離 | ≥ 0 | < 0 | < −3% | < −8% | < −13% |
|---|---|---|---|---|---|
| 現金 | 0% | 30% | 60% | 90% | 100% |

**VIX 領先腿** — 風險分數 `0.55×水位 + 0.30×36月z-score + 0.15×月內飆升`
(水位 = `(VIX−16)/9`,飆升 = `(當月最高 − 近6月均)/12`,三項皆先取 `max(·,0)`):

| 分數 | ≤0.5 | >0.5 | >1.0 | >1.8 | >2.6 | >3.4 |
|---|---|---|---|---|---|---|
| 現金 | 0% | 24% | 42% | 66% | 90% | 100% |

**兩腿的階梯不同,別互相套用。**

參數 `MA12 / lvl1.2` 由 1990–2010 樣本內選出。

⚠ **這裡原本寫「2011–2026 樣本外驗證 Calmar 1.25 > 買進持有 0.75」,那句是錯的**,
來自已被淘汰的「月均價」價格定義;改用月收盤後不成立。PWA 上的同一句已於 2026-08 移除,
這份 README 漏改了。誠實的數字是:OOS 2011–2023 窗口策略 Calmar **落後**買進持有
(0.435 vs 0.528,現金收益 0%/2%/4% 三種假設下都成立);全期優勢(0.337 vs 0.202)
由 2000–2002 與 2008 兩段主導。**這個工具是用報酬換回撤,不是兩者兼得。**
完整基準見 [`ops/CLAUDE.md`](ops/CLAUDE.md) 的「黃金基準」一節。

## 資料來源(逐層自動退回)

**VIX**(固定):GitHub `datasets/finance-vix` 的 `vix-daily.csv`。

**S&P 趨勢腿**,由新鮮到穩定:

1. **自有 Cloudflare Worker** — 使用者在 UI 填網址,存 localStorage。最優先、最穩定。回傳 Yahoo chart JSON 格式。
2. **TwelveData** — 使用者填 API key。盤中即時 SPY。
3. **Yahoo `^GSPC` 經 CORS 代理**(預設、免金鑰)— 依序試 `query1`/`query2` 兩個主機 × `corsproxy.io`/`allorigins` 兩個代理。
4. **Shiller 月頻**(保底)— GitHub `datasets/s-and-p-500`,永遠可用,但延遲約一個月。

**逾時保護:** 每個請求單次上限 7–12 秒,第 3 層整段有 12 秒總預算。任何來源掛掉都不會拖住頁面。

### 已知不可用的來源(別再加回來)

- **Stooq** — 不送 CORS 標頭,瀏覽器直連必失敗;經代理則回傳擋爬蟲的 HTML(HTTP 200 但不是 CSV)。已於 2026-08 移除。
- **FRED `fredgraph.csv`** — 不送 CORS 標頭,瀏覽器無法直接讀。
- 體制層另外實測失敗的七個來源(MacroMicro、AAII、FINRA、TradingEconomics、財政部 383、國發會網站直連、證交所 OpenAPI)逐項理由見 [`ops/CLAUDE.md`](ops/CLAUDE.md)。

## 市場體制與早期警訊(輔助層 · 2026-08 新增)

主畫面下方多一塊面板,回答兩個問題:

1. **目前哪個市場是金融主體** — 對每一對市場算「跟隨者今日報酬 ~ 領先者前一交易日報酬」的 R²,加總後最高者即主體。實測(近兩年、6 個市場):美國 **0.763** ≫ 歐洲 0.159 ≫ 其餘 <0.05,而美國當跟隨者時全部 ≤0.021 —— 沒有市場帶得動美國。
2. **六條外部早期警訊** — 情緒極端貪婪、廣度背離、強度背離、信用需求轉弱、避險需求上升、台灣景氣過熱。

> ⚠ **這層不參與現金水位計算,而且是刻意的。**
> `cash = max(趨勢腿, VIX腿)` 由 440 個月的凍結黃金基準釘住,那是判斷「有沒有改壞」的唯一依據;
> 而新訊號的資料只有 250 天歷史。把它併進去會同時毀掉基準與驗證能力。
> 六條門檻**未經回測**,是常識性極端值,面板上已寫明。由三個測試從三個角度釘死這條邊界。

資料由每日 workflow 產生 `signals.json` 推到 `ops-data` 分支,PWA 從 `raw.githubusercontent.com` 讀(那是少數會送 `Access-Control-Allow-Origin: *` 的來源)。**抓不到就整塊隱藏**,不報錯、不佔版面。

## 本機開發

沒有建置流程,但**必須用 http:// 開**(Service Worker 和跨網域 fetch 在 `file://` 下不會動):

```bash
python -m http.server 8765
```

然後開 http://localhost:8765 。

改完 JS 後如果行為沒變,先確認 SW 沒有餵你舊檔 — DevTools → Application → Service Workers → Unregister,或直接 bump `CACHE` 版本號。

## 已知限制

- **月頻訊號,非日內。** 趨勢腿用月收算 MA12。
- **價格定義是「月收盤」**(2026-08 定案)。Shiller 資料集的 `SP500` 欄是
  「當月每日收盤的**平均價**」—— 已實測與 Yahoo 月均價差異精確為 0.00。
  兩種定義在 17.3% 的月份會給出不同的現金建議,乖離率最大差 10.19 個百分點。
  退回 Shiller 時畫面會出現黃色警示列,不會無聲切換。
- **這個工具是用報酬換回撤,不是兩者兼得。** 1990–2026 月收盤回測(現金不計息):
  最大回撤 -25.8% vs 買進持有 -52.6%,但年化 7.5% 低於買進持有 9.0%。
- **「距高點」的回看區間隨資料源而變** — 走每日 Yahoo 只回看約 10 年,退回 Shiller 可回看到 1871。UI 左上角會標示實際區間,別把「距 10 年高點」讀成「距歷史高點」。
- **缺真實 HY-OAS 信用利差**,純信用事件預警未納入。
- **免費 CORS 代理偶有不穩** — 要長期穩定就自架 Cloudflare Worker(第 1 層)。
- 本機快取(`localStorage`)存的是完整 CSV 原文,約 550 KB。
- **僅供研究,非投資建議,盈虧自負。**
