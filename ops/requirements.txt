# ⚠ 這個檔案開頭有一個 UTF-8 BOM,**請不要把它拿掉。**
#
# pip 讀 requirements 檔時,沒有 BOM 就退回用
# `locale.getpreferredencoding(False)` 解碼。在中文版 Windows 上那是 cp950,
# 於是下面這些中文註解會讓 `pip install -r` 直接【爆掉】:
#
#   UnicodeDecodeError: 'cp950' codec can't decode byte 0xe5 ...
#   exit 2
#
# 2026-10-19 實測(開發機 cp950):原始檔 exit 2、加 BOM exit 0、
# 純 ASCII exit 0、`PYTHONUTF8=1` exit 0。選 BOM 是因為它留得住註解
# (註解在這個專案裡是內容,不是裝飾),而且不需要使用者先設環境變數。
# CI 跑在 UTF-8 的 Linux 上,所以這個 bug 在 CI 永遠不會出現 ——
# 和 cp950 終端機、pytest-cov、pytest major 是同一個形狀的第四次。
# 由 tests/test_dependency_policy.py::test_pip_can_read_every_declaration_file 釘住。
# L1 執行期相依 —— 每日資料健檢、訊號產生、資料鏡像發布真正需要的東西。
#
# ⚠ 這個檔案裡【不放測試工具】。2026-10-19 拆開,理由是量出來的:
# `.github/workflows/daily-health.yml` 的安裝步驟用的就是這個檔案,而安裝失敗
# 會讓整個 job 紅掉 → 健檢不執行 → `steps.check.outputs.code` 是空的 →
# 開 Issue 那一步被跳過 → 心跳也沒有新資料可推。也就是:
# **pytest 裝不起來的那一天,每日資料供應會停,而 Issue 通道完全安靜。**
# 測試工具不在 L1 的執行路徑上,就不該有能力造成那個後果。
# 測試工具見 requirements-test.txt;L2 CI 用的精確鎖定見 requirements-ci.lock。
#
# 這份清單是用 AST 掃 `src/*.py` 與 `scripts/*.py` 的實際 import 得到的,
# 不是憑印象分類(2026-10-19 實測):
#   pandas    engine / backtest / annual_review / fetch_data / health_check / publish_pwa
#   numpy     engine / backtest / annual_review          ← 直接 import,不是只靠 pandas 帶進來
#   requests  fetch_data / fetch_signals / health_check
#   PyYAML    health_check(讀 config.yml)
#
# ── 上界釘到下一個 major 是刻意的 ────────────────────────────────────────
# 黃金基準用 1e-9 精確比對 440 個月,而 CLAUDE.md 明文寫「基準漂移若沒有理由,
# 那就是 bug」。原本全部是無上界的 `>=`,意思是某天 pip 裝到 pandas 3.0、
# rolling/pct_change/groupby 的任一邊界行為改了,基準就會漂 ——
# 而漂移的真正原因會是「裝到新版」,那是最難歸因的一類紅燈,
# 而且它會偽裝成「程式被改壞了」。
#
# ── 下界是一句支援承諾,只能寫進真的驗過的 major ─────────────────────────
# 2026-10-19 加的規則。`pip install -r` 永遠解析到範圍內的最新版,所以下界
# 幾乎不影響 CI 實際跑什麼 —— 它的作用是**宣稱「這些版本我都支援」**,
# 而那是一句可以被驗證的話。驗不出來的 major 就不要寫進去。
pandas>=2.2,<3
# 從 `>=1.26` 收到 `>=2.1`(2026-10-19),兩個獨立理由:
#   1. `>=1.26,<3` 跨過 numpy 1→2 那次破壞性改版 —— 同一份檔案在 2024 年初
#      解析到 1.26、今天解析到 2.x,而這些測試從來沒有在 1.x 上跑過。
#   2. 下界在**維護者自己的機器上裝不起來**:開發機只有 Python 3.13,
#      而 `numpy==1.26.4` 沒有 cp313 wheel,source build 需要編譯器。
# 實測 2.1.2(開發機)與 2.5.4(乾淨 venv 取範圍上界)下,440 個月黃金基準
# 在 1e-9 都零漂移。驗過的是 2.x,所以宣告只寫 2.x。
numpy>=2.1,<3
requests>=2.31,<3
PyYAML>=6.0,<7
